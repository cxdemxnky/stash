Downloader userscripts

Tampermonkey scripts that add checkboxes to videos on member sites and send the selection to the Stash downloader.

Setup

  1. Install Tampermonkey in your browser.
  2. Click Install below (Tampermonkey opens its install page), or Copy and paste into a new Tampermonkey script.
  3. The scripts send downloads to …. If that changes, use the Tampermonkey menu: Set downloader address.
  4. Downloader status: open status page.
